# 🌦️ Atmos – Weather App

Atmos is a weather app where you can check the weather of any city. It also has a fun feature where you guess the temperature before seeing the real temperature.

## Features

- Search for any city.
- Check the current temperature and weather.
- See humidity, wind speed, and other weather details.
- Guess the temperature and check your score.
- Try popular cities using quick-search buttons.
- Works on computers and mobile phones.

## Technologies Used

- HTML
- CSS
- Tailwind CSS
- JavaScript
- OpenWeather API

## How to Run

1. Download the project.
2. Open the folder in VS Code.
3. Add your OpenWeather API key in `script.js`.
4. Open `index.html` using the Live Server extension.
5. Search for a city and enjoy the app!

You need an internet connection to use this app.

## How to Play the Temperature Game

1. Enter a city name, like `Kurnool`.
2. A popup will ask you to guess the temperature.
3. Enter your guess, for example, `31°C`.
4. Click **Reveal actual weather**.
5. See the real temperature and your score.
6. Check the complete weather details.

### Example

- Your guess: 31°C
- Actual temperature: 35°C
- Difference: 4°C
- Score: 89% close!

The score tells you how close your guess was. It is just a fun game score.
